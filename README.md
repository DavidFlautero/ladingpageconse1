# Vehicle Dealership Landing Page

Conversion-oriented dealership landing page built with Next.js, React, TypeScript and Supabase-oriented application infrastructure.

## Overview

This project focuses on the customer-acquisition side of a vehicle-sales workflow: presenting inventory/value propositions clearly, guiding visitors toward contact and supporting integration with a broader dealership application stack.

## Technology

- Next.js 16
- React 19
- TypeScript
- Supabase client
- Tailwind CSS 4
- ESLint

## Engineering focus

- Responsive commercial landing-page design
- Reusable React components
- Lead-oriented user journeys
- Integration readiness for persisted application data
- Production build/deployment workflow
- Separation between marketing presentation and dealership management features

## Development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm start
```
